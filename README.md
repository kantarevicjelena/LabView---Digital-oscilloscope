# Digital Oscilloscope in LabVIEW

This project implements a virtual digital oscilloscope developed in LabVIEW for real-time signal acquisition, visualization, and analysis. The application simulates the functionality of a traditional oscilloscope through a graphical user interface and signal processing tools.

## Project Description

The goal of the project is to create an interactive oscilloscope application capable of:
- Real-time signal visualization
- Signal amplitude and frequency measurement
- Waveform monitoring and analysis
- User interaction through a graphical interface

### The project includes:
- Signal acquisition and processing
- Real-time waveform display
- Measurement and visualization tools
- Interactive LabVIEW front panel

### Technologies Used

1. LabVIEW
2. Signal Processing Tools
3. Virtual Instrumentation

### Project Files

1. DigitalOscilloscope.vi - Main LabVIEW virtual instrument implementing the oscilloscope functionality.
2. SignalProcessing.vi - Module for signal filtering and processing.
3. MeasurementTools.vi - Functions for amplitude, frequency, and waveform analysis.
4. FrontPanelControls.vi - User interface controls and visualization components.
5. Project Documentation.docx - Detailed project documentation including system design, implementation, testing, and functionality analysis.

### Features

- Real-time signal display
- Interactive graphical interface
- Signal measurement and analysis
- Oscilloscope waveform visualization
- Virtual instrumentation implementation
